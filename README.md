# OIBSIP Internship Projects

Welcome to my repository for the Oasis Infobyte Internship Program (OIBSIP). This repository contains beginner-friendly Python projects completed as a part of the internship.

## 🔧 Projects Included

### 1. 🧮 BMI Calculator
A simple Python application to calculate Body Mass Index (BMI) based on user inputs for weight and height.

- Input: Height (cm), Weight (kg)
- Output: BMI value and category (Underweight, Normal, Overweight, Obese)

### 2. 🔐 Password Generator
A secure password generator that creates strong, random passwords based on user-defined criteria.

- Options: Length, use of digits, symbols, lowercase/uppercase letters
- Output: Secure password

### 3. 🌦️ Weather App
A Python script that fetches real-time weather data using an API.

- Input: City name
- Output: Temperature, humidity, description of the weather
